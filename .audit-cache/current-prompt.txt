## Aturan penting
- Jangan audit file di luar .audit-cache/current-batch.txt.
- WAJIB baca setiap file di batch ini secara utuh, bukan menebak dari nama file.
- Kalau batch berisi Livewire class dan Blade pair-nya, audit keduanya sebagai satu pasangan workflow.
- Gunakan konteks project map + livewire map agar tahu file ini ada di workflow/fitur mana.
- Temuan harus spesifik per file.
- Jika file bersih, tetap tulis Status: OK.
- Jangan tulis laporan umum seperti 'pattern sama di semua file'.
- Setelah sebuah file selesai diaudit dan ditulis ke findings, script ini akan menandai [x] di checklist.
- Format output antar file HARUS seragam.

## Format append ke findings
