# Auto-Commit & Pull Request Setup

## How It Works

Every 6 hours, the autonomous development cycle:
1. **Picks task** from queue
2. **Runs OpenCode** with agent context (FE/BE/QA)
3. **Executes tests** (E2E/Unit)
4. **Auto-fixes lint** if needed
5. **Commits changes** with structured message
6. **Creates PR** automatically (if GitHub configured)

---

## Auto-Commit Format

```
feat($task_type): $task_title

Task: $task_id
Agent: $task_type
Automated: yes
```

**Example:**
```
feat(frontend): Fix face-api.js import

Task: FE_FACE_IMPORT
Agent: frontend
Automated: yes
```

## Auto-PR Creation

### Prerequisites

Set these environment variables (in `.env` or shell):

```bash
# GitHub Configuration (required for PR creation)
GITHUB_TOKEN="your_personal_access_token"
GITHUB_REPO_OWNER="your-username-or-org"
GITHUB_REPO_NAME="hrconnect"
GITHUB_PR_ASSIGNEE="username"  # Optional
GIT_BASE_BRANCH="main"  # Optional, default: main
```

### PR Title & Body

**Title:** `feat: [Task Title]`

**Body:**
```
Generated by HRConnect autonomous development workflow.

**Task:** FE_FACE_IMPORT  
**Type:** frontend  
**Agent:** FRONTEND

## Changes
Automated implementation of task: Fix face-api.js import

## Validation
✅ Unit tests passed  
✅ Integration tests passed  
✅ Linting clean  
✅ Build successful  

## Test Results
See logs: .hermes/cron-logs/20260711.log

---
*This PR was automatically created. Review before merging.*
```

### Labels

- `automated`
- `feature`
- `frontend` / `backend` / `e2e`

### Assignee (optional)

Set `GITHUB_PR_ASSIGNEE` in environment.

## File: `.hermes/auto-pr.sh`

**Purpose:** Create GitHub Pull Request after successful task

**Usage:**
```bash
bash .hermes/auto-pr.sh TASK_ID TITLE TASK_TYPE LOG_DIR
```

**Logic:**
1. Check GitHub token configured
2. Create feature branch: `task/{task_id}`
3. Push branch to remote
4. Create PR via GH CLI or GitHub API
5. Log PR number to file

**Exit Codes:**
- `0`: PR created successfully or skipped (no GitHub config)
- `1`: GitHub token not configured (graceful skip)
- `2`: Branch push failed
- `3`: PR creation failed

---

## Manual PR Trigger

## GitHub Personal Access Token

Create token with permissions:
- `repo` (full control of private repos)
- `public_repo` (for public repos)
- `workflow` (trigger workflows)

**Security:** Store in `.env` (not committed to repo!)

---

## What Happens Without GitHub Config?

If `GITHUB_TOKEN` not set:
- ✅ Auto-commit still works
- ✅ Changes staged and committed
- ⚠️ PR creation skipped (graceful)
- ✅ Logs warn: "GitHub token not configured - skipping PR creation"

You can still manually create PR after review.

## Troubleshooting

### "Failed to push branch"

**Cause:** Branch already exists or permission issue

**Fix:**
```bash
git checkout main
git branch -D task/{task_id}  # Delete if exists
git push origin --delete task/{task_id}
```

### "Could not create PR"

**Cause:** Invalid GitHub token or repo name

**Fix:**
```bash
# Verify token
echo $GITHUB_TOKEN

# Test GitHub API
curl -H "Authorization: token $GITHUB_TOKEN" https://api.github.com/user
```
